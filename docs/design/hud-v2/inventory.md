## Task and status overlays

| Surface                      | What it contains                                                                                                                                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Walk camera and capture      | In-page camera or device file/camera picker, shutter, retake and close. The capture sheet adds pose nudges, note, tags and request association, Save, progress, and success or error. Recovery notices handle an interrupted capture. |
| Measure                      | A temporary reticle and point controls, distance, model-local coordinates, clear, and exit.                                                                                                                                           |
| Render                       | Desktop render settings, progress and completion controls, image output, and an exit. It has a separate measuring route.                                                                                                              |
| Startup, hints, and feedback | Sakuga loading progress, first-use gesture help, save status, warnings, request badges and toasts. These appear at their relevant stage or task.                                                                                      |
| Diagnostics                  | Optional performance readout and the HUD and render measuring routes. These are opt-in from Tools or their addresses.                                                                                                                 |
| In-scene overlays            | Room names, compass markers, selection outlines and edit handles, photo and request markers, and measurement endpoints. They are positioned with the model and can compete for space with screen-edge controls.                       |
| Catalogue and piece pages    | The catalogue has its own browsing controls. The piece page has a 3D inspector, dimensions, views, photos, uses and placement flows. These are adjacent screens rather than viewer modes.                                             |

## Gaps to address in the next concepts

- **Walk changes visual language.** Orbit uses clear, quiet corners. Walk puts exit, camera view, location, tilt, help and requests into one wrapping bar of paper controls, with a second orientation display and a separately framed map. Keep exit and the camera view choice easy to find and move occasional controls into their own disclosure.
- **The minimap carries expanded-map detail at rest.** The current Walk minimap draws much more than the earlier mock's light floor outline and pink heading marker. Use a simpler compact drawing and an expanded paper map with the additional geometry, labels and actions. The two sizes need to read as the same map at different levels of detail.
- **Edit starts with catalogue density.** The full Furniture panel opens on entry and combines browsing, editing, settings and status. Try an Edit state with the canvas open, a visible Add entry, and controls for the current selection. Show the catalogue only when adding and give slower settings a separate place within the existing editor.
