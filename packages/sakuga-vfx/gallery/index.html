Sakuga VFX

Twelve ordinary controls that react like anime: squash and overshoot on springs, and drawn effects (smoke, impact bursts, splashes, slashes) with manga sound-effect lettering. Each one is a single file with no dependencies.

The repo on GitHub ↗ @crtvTeknologist on X ↗

Effects are drawn on one canvas over the page and switch off for prefers-reduced-motion. Every colour is a --sk-* variable you can override.
