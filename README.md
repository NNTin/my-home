# Render shots

Before/after renders of the house **model** for pull requests that change how it is drawn
(`docs/design/realistic-render.md` §11.4). One folder per pull request, `pr-<number>/`, JPEG, at most
300 kB each; pull requests link the files by commit.

Only renders of the model belong here: never a photo, and nothing that shows a photo (the gallery,
"view from here" with an overlay). This branch has no code and no workflows and is never merged.
